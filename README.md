# GWW-RGSS Issue Tracker

Report bugs and suggest improvements for GWW-RGSS projects here. Application source code is maintained in separate repositories.

## Submit an issue

[Report a bug or request a feature](https://github.com/GWW-RGSS/issues/issues/new/choose)

Before submitting, [search existing issues](https://github.com/GWW-RGSS/issues/issues) to see whether someone has already reported the same problem. Add relevant details to an existing report when possible.

- **Bug report:** Explain what happened, what you expected, and how to reproduce it. Include your browser/device and screenshots when useful.
- **Feature request:** Describe the problem you want solved and your proposed improvement.
- Select the affected area in the form, or choose **Not sure**.

Use a descriptive title and submit one problem or suggestion per issue.

## Public reports

Issues and attachments are publicly visible. Remove passwords, access tokens, classroom codes, and personal information from screenshots and logs before posting.
